# 验证范围

首个公开版本为 0.0.1。此前 0.1.x 仅用于本地开发和隔离升级验收，不构成公开版本历史。

## 已执行

- Go 回归、vet、格式与安装器策略检查。
- PATH 原始字节和类型保真，缺值、空项、重复项和顺序保持。
- 恢复前保护快照、预览过期拒绝、授权取消、读回不符与回滚故障处理。
- 首次引导创建第一份快照、备份结果查看、恢复结果和保护快照撤回。
- 私有非输入桌面上的真实独立测试安装、桌面／开始菜单入口、首次运行、尚未备份时升级。
- 实际更新准备、重复检查复用、普通退出后下次启动更新，以及确认重启更新。
- 实际合成用户 PATH 的恢复和撤回，更新后快照逐文件摘要保持。
- HTTP 更新源失败、目录不可用及恢复后的状态清除。
- 独立测试安装的卸载、重装保留快照、设置与执行记录。
- 回环 HTTP／SOCKS5 认证代理下载、签名校验及更新流程。
- 非输入桌面焦点监测，验收前后真实 PATH 比对不变。

## 边界

独立测试安装通过，不等同于所有用户设备的固定安装目录、Explorer 通知区域、登录自启、不同管理员 UAC 和多显示器物理 DPI 均已通过。公开体验版仍需要不同设备继续反馈。

Windows 安装器目前没有公众信任的 Authenticode 签名。更新包由应用固定的独立公钥验证，两个签名机制分开说明。

验收脚本在 `tests/e2e`；会创建窗口的脚本必须先验证真实线程位于独立非输入桌面，不能只通过环境变量放行。普通 `go test ./...` 不启动用户桌面窗口或修改真实 PATH。

原始验收截图、日志、个人目录和运行数据不进入公开仓库。问题反馈请先去除 PATH、代理口令和个人文件名等敏感内容。
