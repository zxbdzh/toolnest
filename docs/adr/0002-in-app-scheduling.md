# 计划随工具箱进程运行，退出后停止

旧原型通过 Windows 任务计划在界面退出后备份；用户明确要求计划属于软件自身，并在 Q04 接受托盘继续、退出或休眠暂停、恢复运行后漏跑合并补一次。因此 ToolNest 使用应用内调度，不通过系统计划任务或常驻服务维持退出后的执行。

这一选择使后台运行状态与用户的关闭选择一致，但必须明确区分隐藏到托盘和退出。补跑检查的是恢复运行时的当前 PATH，不能还原停机期间的历史；Q06 进一步确认无变化时只保留检查记录。旧版系统计划的识别与确认停用属于迁移功能，不是新调度器的依赖。

依据：[正式规格中的应用内计划与迁移决定](../specs/toolnest-v1.md)。
