# ToolNest 0.0.4

- 重新打磨首页、设置和快照页面，采用悬浮导航、统一控件与更紧凑的排版。
- 内置 MiSans 字体，提供小、标准和大三档字号。
- 应用内毛玻璃不依赖 Windows 透明效果开关，支持明暗主题。
- 调整导航切换、按钮按压和弹层动效，支持减少动态效果。
- 移除系统标题栏，将窗口按钮融入软件顶栏；保留拖动、双击最大化、窗口缩放与关闭确认。
- 修复快照详情页签的选中底与文字错位，切换后准确居中。
- 同步修正主题、字号、关闭行为、代理和备份计划等分段控件的对齐。
- 分段控件按实际内容收口，去掉横贯详情区域的多余背景条。
- 去掉侧栏选中项右侧的小圆点，保留磨砂选中底色。
- 改善快照查看、批量选择与恢复确认，保留键盘和辅助功能操作。
- 修复隐藏到托盘后，临时托盘失联或后台状态变化导致窗口意外显示的问题。
- 改善更新时程序文件短暂占用的处理，失败时保留原版本与处理入口。

覆盖安装保留配置、快照、自动备份计划和执行记录，不需要先卸载。
安装前请正常退出旧版，包括托盘；安装完成不会自动打开软件。

这是正常使用真实 PATH 的安装包，不包含合成 PATH 或更新测试入口。
安装器尚未做 Windows 代码签名，系统可能显示“未知发布者”；应用更新包保留独立签名校验。
