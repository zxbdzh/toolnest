# ToolNest 0.0.1

ToolNest 首个公开体验版，面向 Windows 11 x64。

- 查看、搜索和复制用户与系统 PATH，保留原始顺序、重复项和变量。
- 手动保存快照、比较变化；恢复前预览所选范围，并自动保存保护快照。
- 备份完成可直接查看本次快照；恢复结果显示各范围状态，可再次预览并确认撤回。
- 提供应用内自动备份计划，支持间隔与每日定时，隐藏到托盘时继续运行。
- 首次引导可创建第一份快照；设置支持明暗主题、关闭行为和可选开机自启。
- 公共代理支持跟随系统、直连、HTTP 与 SOCKS5，供更新等联网功能共用。
- 更新下载后由用户决定重启或下次打开生效；失败保留可用版本和处理入口。
- 中文安装向导，统一应用、任务栏与托盘图标，提供桌面和开始菜单入口。

安装前请正常退出旧版 ToolNest，包括托盘。安装器不会修改 PATH；恢复功能会在预览确认后写入所选范围。卸载保留快照、设置和执行记录。

本版安装器尚未做 Windows 代码签名，系统可能显示“未知发布者”。应用更新包具有独立签名校验。首次公开版本尚无可升级目标，后续版本发布后才会发现更新。

曾安装本地 0.1.x 测试版的用户，请先正常退出，再手动覆盖安装此版；首个公开版本号为 0.0.1，不会自动把较高的测试版本号降级。
