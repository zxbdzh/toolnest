# ToolNest 0.0.2

- 重新打磨首页、设置和快照页面，采用悬浮导航和统一的胶囊按钮。
- 软件内部毛玻璃不依赖 Windows 透明效果开关，深浅主题保持一致。
- 内置 MiSans 字体，提供小、标准和大三档字号。
- 调整导航切换、按钮按压和弹层动效，支持减少动态效果。
- 改善快照查看、批量选择与恢复确认，保留键盘和辅助功能操作。
- 修复隐藏到托盘后，托盘短暂失联或后台状态变化意外显示窗口的问题。

这是正常使用真实 PATH 的安装包，不包含合成 PATH 或更新测试入口。
升级前请正常退出旧版 ToolNest，包括托盘；安装器不会强制关闭应用，也不会在完成后自动打开窗口。
覆盖安装保留原来的配置、快照、计划和执行记录，不需要先卸载。

安装器尚未做 Windows 代码签名，系统可能显示“未知发布者”；应用更新包保留独立签名校验。
